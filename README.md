# TurboRUL – Aircraft Engine Remaining Useful Life Prediction

An end-to-end Machine Learning project for predicting the **Remaining Useful Life (RUL)** of aircraft turbofan engines using the NASA C-MAPSS FD001 dataset.

TurboRUL applies data preprocessing, feature extraction, machine learning model comparison, and predictive analytics through an interactive Streamlit dashboard.

## Project Overview

Aircraft engines gradually degrade during operation. Predicting their remaining useful life can help support predictive maintenance by estimating how many operating cycles remain before an engine reaches its end-of-life condition.

TurboRUL uses historical engine sensor measurements to estimate Remaining Useful Life (RUL) and presents the results through an interactive dashboard.

## Key Features

- Data preprocessing and cleaning
- Exploratory data analysis and sensor analysis
- Feature extraction and feature selection
- Outlier detection using Isolation Forest
- Feature selection using Recursive Feature Elimination (RFE) and Lasso
- Comparison of multiple regression algorithms
- Gradient Boosting Regressor as the selected model
- Remaining Useful Life prediction
- Interactive Streamlit dashboard
- Visual analytics using Plotly

## Machine Learning Workflow

1. **Data Collection:** Load the NASA C-MAPSS FD001 turbofan engine dataset.
2. **Data Preprocessing:** Clean and prepare the sensor and operational data.
3. **Feature Engineering:** Extract and select useful features.
4. **Model Training:** Train and compare regression algorithms.
5. **Model Selection:** Select the Gradient Boosting Regressor.
6. **Model Saving:** Save the trained model, scaler, feature information, and evaluation metrics.
7. **Prediction:** Estimate engine Remaining Useful Life.
8. **Visualization:** Display predictions and analytical insights through the Streamlit dashboard.

## Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/TurboRUL.git
cd TurboRUL
```

Replace `YOUR_USERNAME` with your GitHub username.

### 2. Create a Virtual Environment

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

On macOS/Linux:

```bash
source venv/bin/activate
```

### 3. Install Dependencies

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Run the Streamlit Dashboard

```bash
streamlit run app.py
```

The dashboard will open in your browser.

## Dataset

This project uses the **NASA C-MAPSS Turbofan Engine Degradation Simulation Dataset (FD001)** from the NASA Prognostics Center of Excellence.

The dataset is included in this repository, so you do not need to download it separately.

**Dataset Location:**

```text
data/
├── raw/
│   └── CMAPSSData/
│       ├── train_FD001.txt
│       ├── test_FD001.txt
│       └── RUL_FD001.txt
│
└── processed/
    └── df_final_clean_FD001.csv
```

### Dataset Files

| File | Description |
|---|---|
| `train_FD001.txt` | Training data containing engine operational and sensor measurements |
| `test_FD001.txt` | Testing data containing engine operational and sensor measurements |
| `RUL_FD001.txt` | Actual remaining useful life values for the test engines |
| `df_final_clean_FD001.csv` | Preprocessed dataset generated by the preprocessing pipeline |

Original dataset source:

[NASA Prognostics Center of Excellence – Dataset Repository](https://www.nasa.gov/intelligent-systems-division/discovery-and-systems-health/pcoe/pcoe-data-set-repository/)

Dataset attribution: NASA C-MAPSS Turbofan Engine Degradation Simulation Dataset.

## Running the Notebooks

Open the project in Jupyter Notebook or VS Code.

Run the notebooks in this order:

1. `01_data_preprocessing.ipynb` – performs data preprocessing and generates the cleaned dataset.
2. `02_model_training.ipynb` – performs feature engineering, model training, evaluation, and model saving.

The required raw and processed dataset files are included in the repository.

## Model

The project evaluates multiple regression algorithms and selects a Gradient Boosting Regressor for RUL prediction.

The trained model and supporting files are stored in the `models/` directory.
